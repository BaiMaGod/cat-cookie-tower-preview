# 猫咪饼干塔 — Three.js MVP V1.2

这是按照《猫咪饼干塔 MVP 游戏设计文档 V1.0》实现的 V1.2 可玩原型。核心规则已经写入独立逻辑层并通过 Node 自动测试。

## 运行

项目使用 ES Modules，不能直接双击 `index.html`。

### Windows

双击：

```text
start.bat
```

然后打开：

```text
http://localhost:8080
```

### macOS / Linux

```bash
./start.sh
```

或者：

```bash
python3 -m http.server 8080
```

再访问 `http://localhost:8080`。

## Three.js 依赖

启动器会按以下顺序加载 Three.js 0.186.0：

1. `vendor/three.module.js`（离线本地版）
2. jsDelivr CDN
3. unpkg CDN

当前交付包没有内嵌 Three.js 官方库文件，因此**正常首次运行需要联网**。如果要完全离线运行，请按 `vendor/README.md` 将官方 r186 的 `three.module.js` 和 `three.core.js` 一起放入 `vendor/`。

## 操作

- 手机：左右拖动屏幕旋转饼干塔。
- PC：按住鼠标左右拖动。
- 猫咪自动弹跳。
- 每次重新起跳：剩余弹跳次数 `-1`。
- 每完整穿过一整层饼干：`+1`。
- 一层一层稳定下降：长期净消耗约为 `0`。
- 连续穿 N 层：相对单层可净赚 `N-1` 次弹跳。
- 落到烧焦危险区：立即失败。
- 弹跳次数耗尽：猫咪落地后无法再次起跳。

- 连吃 Combo 与倍率得分

## 代码结构

- `src/boot.js`：Three.js 本地/CDN 回退加载与启动错误提示。
- `src/logic.mjs`：规则、角度判定、可控随机平台生成。
- `src/main.js`：Three.js 场景、角色、平台、运动、碰撞、动画、输入和 UI。
- `tests/logic.test.mjs`：核心规则自动测试。
- `docs/游戏设计文档_V1.0.md`：对应的设计文档。
